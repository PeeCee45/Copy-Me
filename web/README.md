# Copy Me website (Next.js)

    npm install
    npm run dev      # opens at http://localhost:3000

Edit your download links in `app/links.js`. Everything else is in `app/page.js` and `app/globals.css`.

## Put it online (free, on Vercel)
1. Push the repository to GitHub.
2. At vercel.com choose "Add New Project" and import it.
3. Set **Root Directory** to `website`, then Deploy.
